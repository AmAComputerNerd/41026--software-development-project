Feature: Notifications, AI Chat Assistant & MCP/RAG Integration

This service manages a student's notifications, delivery preferences, AI Chat Assistant sessions, and shared MCP/RAG integrations. Core functionality:

- Notifications: create/read notifications with StudentId, Type (Deadline/Grade/Automation/Account/AI), SourceMicroservice, Message, IsRead flag, and CreatedAtUtc; list/filter, mark as read/unread, delete notification, and push new notifications from other services via HTTP and real-time SSE stream.
- NotificationPreferences: per-student preferences keyed by NotificationType and NotificationChannel (InApp/Email) with Enabled flag and UpdatedAtUtc.
- AI Chat Assistant: persistent session-based conversation assistant (ChatSessions and ChatMessages in PostgreSQL) replacing static digests. Every new chat session automatically generates an unread notification summary as its opening greeting with an animated Neobrutalist loader. Supports a collapsible Past Chats drawer.
- Shared MCP Tool Integration: exposes shared tool `notifications_broadcast_alert` on the non-containerised MCP server, reachable via `IMcpClient` and `/api/notifications/mcp/broadcast` with urgency validation and structured content.
- Shared RAG Query Integration: consumes the shared local RAG server via `IRagClient` and `/api/notifications/rag/query`, returning grounded answers with citations and confidence metrics (HIGH/MEDIUM/LOW/INSUFFICIENT_CONTEXT) for course policies and deadlines.
