Feature: Deadlines and Task Tracker

Help students organise coursework, see upcoming deadlines and turn assignments
into manageable plans. This slice includes the task-tracker UI, public API and
private persistence service.

Core feature scope:
- Create, edit and remove tasks and nested sub-tasks, with optional due dates
  and course links, priorities and completion states.
- Find coursework through a searchable, filterable task list, monthly calendar
  and Canvas assignment view. Completing a parent completes its descendants.
- Sync Canvas courses and assignments without duplicates, preserving local
  planning edits while keeping official assignment details read-only.
- Generate assignment sub-task plans and editable task-description drafts
  through AI Mode.
- Send due-soon reminders through the shared notification service.
- Provide an optional AI assistant: MCP reads live upcoming deadlines and opens
  tasks; RAG explains documented feature behaviour with sources and confidence,
  not live task data. Ordinary task views remain usable without these services.
